API REST de Estudiantes con FastAPI

Proyecto final para la gestión de estudiantes usando FastAPI y SQLite3.

Rutas principales

  • POST /students
  • GET /students
  • GET /students/{id}
  • PUT /students/{id}
  • DELETE /students/{id}
  • POST /students/bulk
  • GET /students/average
  • GET /students/table

Para probar la API ingresa a: /docs

Para ver la tabla HTML parcial: /students/table
